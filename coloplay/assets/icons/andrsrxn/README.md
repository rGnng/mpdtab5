# andrsrxn icons

`bluetooth-connecting.svg` is the former disconnected indicator. `usb.svg` and
`bluetooth.svg` supply the USB serial/Bluetooth connection indicators.

Original icons: https://github.com/andrsrxn/icons, obtained from Iconify's
`json/andrsrxn.json` collection. Copyright 2026 Andrés Raxón, MIT (LICENSE).
The checked-in SVGs are rasterized locally; firmware never contacts Iconify/CDNs.
Connection source hashes are recorded in `../connection-icons.json`.
